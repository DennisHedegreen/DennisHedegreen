# Hedegreen Research

Independent research, data surfaces, tools, and public build work by Dennis Hedegreen.

I build things that can be checked: public datasets, small tools, protocol proofs, research notes, interactive rooms, and reproducible artifacts.

This is work, not profile theater.

## Research and Observation

- [Where Does the Function Go](https://github.com/DennisHedegreen/where-does-the-function-go) — pre-results research software for persistent constraints and recoverability in language models. Experimental scaffolding, not a demonstrated research result.
- [Circuit Lab](https://github.com/DennisHedegreen/elliot-lab) — a local graphical workbench for controlled circuit experiments. The related [TID demo](https://hedegreenresearch.com/tid/circuit-lab-demo/) is narrower than the full workbench.
- [bio-log](https://github.com/DennisHedegreen/bio-log) — dated observations and photographs of one glass vessel.
- [Lab Results](https://github.com/DennisHedegreen/Hedegreen-Research-Lab-Results) — small experiment and warmup data packs; warmups are not benchmarks.

## Software and Reproducible Artifacts
