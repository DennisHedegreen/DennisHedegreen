## Current Public Repos

- [p4p](https://github.com/DennisHedegreen/p4p) — protocol proof and reference runtime for direct restaurant-customer discovery, signed node identity, registry failover, and modular pilot lanes.
- [hedegreen-research-transparency](https://github.com/DennisHedegreen/hedegreen-research-transparency) — public declarations ledger for Hedegreen Research.
- [danish-politics-data](https://github.com/DennisHedegreen/danish-politics-data) — Denmark-only public politics data surface for municipality-safe Folketing analysis.
- [swedish-politics-data](https://github.com/DennisHedegreen/swedish-politics-data) — Sweden-only public politics data surface for municipality-safe Riksdag analysis.
- [nabour](https://github.com/DennisHedegreen/nabour) — small Denmark ↔ Sweden municipality matcher.
- [nearest-gravhoj](https://github.com/DennisHedegreen/nearest-gravhoj) — one-button field tool for finding the nearest registered Danish gravhoj.
- [bio-log](https://github.com/DennisHedegreen/bio-log) — simple daily observation log of a water glass vessel.
- [gtk-launcher](https://github.com/DennisHedegreen/gtk-launcher) — GTK3 desktop launcher with setup wizard, Claude + Codex CLI, i18n, and theme support.
